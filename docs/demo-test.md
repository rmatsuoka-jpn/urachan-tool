# v0.2.0 追加検証項目

旧版データの自動移行はありません。更新前に必要な定型文を控えてください。

1. 起動直後に定型文だけが表示されること
2. 設定 → 表示する機能で「日付ツール」をONにし、上部タブから開けること。OFFに戻しても定型文データが消えないこと
3. 西暦2026→令和8年、2019→令和元年／平成31年、1989→平成元年／昭和64年。和暦令和8年→2026年。月日の入力が必要ないこと
4. うるう日の加減算、曜日、および今日の日付コピーが動くこと
5. 組織共通JSONを取り込み前に確認できること。共通セットをOFFにすると全定型文タブから非表示、ONで再表示されること
6. 開発者メニューのJSON書き出し時は初期状態でこのPCに反映されないこと。チェックONなら反映されること
7. セット詳細から削除したときだけ関連する共通のお気に入りが削除され、個人定型文は残ること
8. バックアップ→一時的な設定変更→復元で、定型文／お気に入り／表示機能／共通の有効状態が戻ること
9. 設定の説明「？」がクリックで開くこと。サイドパネルの開閉ができること

# 職場PCでのデモ確認手順（v0.1.1）

## 前提

- WindowsなどでChrome 116以上を利用できる
- 職場PCでローカル拡張の読み込みが許可されている（ユーザー確認済み）
- 外部通信・外部CDN・ログインは不要
- **実際の業務情報・個人情報を試験データに使わない**
- v0.1.0のローカル読み込みは確認済み。更新・再読み込みの可否は未確認。検証項目に含める

## 1. 拡張機能の読み込み

1. GitHubの [Releases](https://github.com/rmatsuoka-jpn/urachan-tool/releases) を開く
2. Assetsから `urachan-tool-v0.1.1.zip`（または最新バージョン）を選ぶ。**Source code (zip) は選ばない**
3. ダウンロードしたZIPを展開する。中身は `manifest.json`、`background.js`、`panel.html`、`panel.css`、`panel.js` の5ファイルだけ
4. Chromeで `chrome://extensions` を開く
5. 右上の **デベロッパーモード** をONにする
6. **パッケージ化されていない拡張機能を読み込む** を選ぶ
7. ZIPから展開した、`manifest.json` が直下にあるフォルダを選択する
8. ツールバーの拡張機能メニューから「うらちゃんツール」を開く（必要に応じてピン留め）

※ 配布・導入は所属組織のポリシーに従ってください。

## 2. 画面操作の確認

- [ ] サイドパネルが開く
- [ ] 上部の「× とじる」でサイドパネルを閉じられる（一覧と設定の両方）
- [ ] 登録済みのお気に入り★が黄色、未登録の☆がグレーで表示される
- [ ] タブと一覧のラベルが「組織共通」になっている
- [ ] 起動直後はシンプルモード
- [ ] 「＋ 新しく登録」から架空の定型文を保存できる
- [ ] 一覧の文章部分をクリックするとコピーされ、他の画面へ貼り付けられる
- [ ] ★を押してもコピーは発生しない
- [ ] 名前・本文で検索できる
- [ ] タブ「すべて／お気に入り／個人／組織共通」が切り替わる
- [ ] 個人用の編集・削除と削除直後の「元に戻す」が使える
- [ ] [設定]→[共通定型文を取り込む]から、開発者モードで自作・書き出した架空データの共通JSONを読み込める
- [ ] 共通文を「複製」すると個人用として編集できる
- [ ] 同じ共通JSONを再び取り込んでも重複せず、個人用の定型文は残る
- [ ] 設定で拡張モードにするとメニューが表示される
- [ ] モードを戻してもデータが残る
- [ ] 個人データのバックアップ・復元ができる

## 3. 開発者機能の確認

1. **設定**を開く
2. 下部の「うらちゃんツール v0.1.1」を5回連続でクリックする
3. 「開発者用メニュー」の「共通JSONを作成・編集」を開く
4. 「＋ 新しいセットを作成」で架空のセット名を入力する
5. 架空の定型文を追加し、「JSONを書き出す」を押す
6. 書き出したJSONを、設定の「共通定型文を取り込む」で読み込めることを確認する
7. 設定に戻り「開発者モードを終了」で隠せることを確認する

## 4. Chrome再起動と更新確認

- [ ] Chromeを終了→再起動しても保存データが残る
- [ ] 同じフォルダのプログラムを更新した後、`chrome://extensions` の対象拡張で **再読み込み** できるか
- [ ] 再読み込み後も個人用定型文・共通定型文・お気に入りが残る
- [ ] ソースコードを別フォルダへ変更したときの手順・制限を記録する

**注意：** 拡張機能を削除すると、その拡張機能のローカル保存データは失われる場合があります。削除する前にバックアップを保存してください。

## 5. 問題が出た場合

- パネルが開かない：拡張機能を再読み込みし、`chrome://extensions` のエラー表示を確認
- コピーできない：パネルを開き直し、コピー先への貼り付けを再試行
- JSONを取り込めない：ファイルの種類が「共通JSON」か「個人バックアップ」かを確認
- 設定が消えた：Chromeプロファイルが変わっていないか、拡張機能を削除していないか確認
