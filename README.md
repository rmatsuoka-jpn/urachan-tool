# urachan-tool（うらちゃんツール）

自治体などの**閉域ネットワーク内で利用する、Chromeサイドパネル型の業務支援ツール**を開発するプロジェクトです。

> **現在の状態：設計・開発準備段階（未実装）**  
> Chrome拡張機能の動作版はまだありません。まず「定型文コピー」を実装し、使い勝手を検証します。

## プロジェクトの目的

- 既存のイントラネットや業務システムを改修せず、ブラウザ側に便利な機能を追加する。
- **説明書なしで使える**分かりやすい画面を目指し、問い合わせや運用負担を抑える。
- インターネット接続や外部サーバーへの依存を設けない。
- 小さな機能から実装し、将来的に文字変換・日付ツールなどを追加できる構成にする。

## 最初に作るもの：定型文コピー

Chromeのサイドパネルから、よく使う文字・文章を**行クリックでコピー**する機能です。

| 機能 | 計画 |
| --- | --- |
| 定型文の登録・検索・コピー | 個人用の文字列・複数行の定型文に対応 |
| タブ切り替え | すべて／お気に入り／個人／共通 |
| お気に入り | 個人用・共通を区別せず設定可能 |
| 組織共通の定型文 | JSONファイルを手動取り込み |
| 共通定型文の編集 | 元データは直接編集せず、個人用にコピーして編集 |
| 個人データの移行 | JSONバックアップ・復元 |
| シンプルモード | 初期モード。日常のコピー操作を中心に表示 |
| 拡張モード | 機能別メニューと高度な管理操作を表示 |

※この表は**実装済み機能の一覧ではなく、計画している仕様**です。

## 画面設計の考え方

**シンプルモードを初期値**にし、初めて使う職員が説明書なしで操作できることを重視します。拡張モードへ切り替えると、今後追加する「定型文」「文字変換」「日付ツール」「便利ツール」などのメニューを利用できる想定です。

どちらのモードでも登録したデータは共通です。モードを切り替えてもデータは消えません。

## 想定技術（設計段階）

- Google Chrome 拡張機能（Manifest V3）
- Chrome Side Panel API
- Chrome Storage API（原則 `chrome.storage.local`）
- ローカルファイルによるJSON入出力
- 外部CDN、クラウドAPI、アクセス解析、外部サーバー取得は利用しない方針

> Chrome拡張機能の**本番配布方法は未決定**です。管理対象端末におけるインストールや更新は、所属組織のChrome管理ポリシーを確認したうえで設計します。

## 情報管理に関する注意

このリポジトリは**公開（Public）**です。住民・職員などの個人情報、実際の定型文、庁内の機密情報、認証情報、内部システムの構成情報などはコミットしないでください。テストには架空のサンプルデータを使用します。

開発環境はインターネット上のGitHubで管理できますが、閉域ネットワークへの導入時は、組織で認められた手段でファイルを移送・配布する必要があります。**GitHubから閉域内の端末が直接取得する前提ではありません。**
