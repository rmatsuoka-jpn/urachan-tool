# うらちゃんツール / urachan-tool

自治体などの閉域イントラネットでも使える、外部通信なしのChromeサイドパネル型業務ツールです。既存システムの改修、サーバー、CDN、ビルド環境を必要としません。

**最新：v0.5.0（オフライン画像変換を追加。v0.4.0の「あとで見る」機能も維持）**。既存の定型文と日付ツールは維持しています。追加画面は職場PCでの実機確認が必要です。

## v0.5.0 の変更点：画像変換

- 「＋ 機能」→「表示する機能」で**画像変換**を有効化できます。初期表示は従来どおり「定型文」のみです。
- JPEG / PNG / HEIC / HEIFを、ファイル選択または**ドラッグ＆ドロップ**で追加。最大30枚・1枚50MB・合計250MB（処理時の画素数上限4,800万）。
- **長辺サイズ**：変更しない／1600px（初期値）／1200px／800px。縦横比維持、元画像より小さいものを拡大しません。
- **保存形式**：JPEG（初期値）／PNG。JPEGの画質は40〜100%（初期値80%）。PNGでは画質設定を非表示にします。
- **HEIC → JPEG/PNG**：ローカル同梱のlibheifによるデコード後、ChromeのCanvasで保存形式に変換。入力の種類によって非対応画像や色・向きに差が出る場合があるため、職場PCの実画像で要確認です。
- **一覧**：元ファイル名・容量・進捗・変換後容量・削減率・失敗理由を表示。個別除外と全件削除ができます。
- **保存**：変換成功が1枚なら画像ファイル、複数ならZIPを1回ダウンロード。同じ出力名は連番にして衝突回避します。失敗した画像は結果に含めず、画面で知らせます。
- **プライバシー**：画像をサーバーに送信せず、Chromeの保存領域・JSONバックアップにも入れません。出力ではEXIF（撮影日時・GPS等）は原則引き継ぎません。透過PNG→JPEGの背景は白になります。
- **権限**：新しいサイトアクセス権限やダウンロード権限は要求しません。HEIC用のWebAssemblyに限り、Chrome拡張のCSPに`wasm-unsafe-eval`を指定します。
- **配布物**：画像変換スクリプト、同梱ライブラリ、ライセンス文書をリリースZIPに含めます。ソース・第三者ライセンスは下の「ライセンス」を参照してください。

### 画像変換の使い方

1. 「＋ 機能」→「表示する機能」で「画像変換」をONにします。
2. 上部の「画像変換」タブを選択し、画像をドロップするか「ファイルを選択」を押します。
3. サイズ・保存形式・必要ならJPEG画質を選び、「○枚を変換して保存」を押します。
4. 1枚は画像、2枚以上の成功結果はZIPとして、Chromeのダウンロード先に保存されます。元画像は変更されません。

**実機確認**：HEICの実画像（縦・横・異なるiPhone撮影設定）、大量画像、組織ポリシー下のダウンロード動作は未検証です。まずテスト用の画像でご確認ください。

## v0.4.0 の変更点

- **一覧をコンパクトに整理**：検索1行、★絞り込み・タグ・保存日・並び替えを次の1行にまとめ、最初の5件だけ表示。「もっと表示する」で5件ずつ追加
- **保存日時を表示**：ブックマークに登録した日付と時刻を表示。メール受信日ではなく、保存日時で「今日／7日以内／30日以内／期間指定」をフィルター
- **★お気に入り**：一覧の☆／★をクリックして設定。★のみの絞り込みと、★優先（同一グループは新しい順）の並び替え
- **並び替え**：新しい順（初期値）／古い順／★優先／タイトル順
- **クリック領域を明示**：タイトル部分を淡い背景色のボタンにして、ホバー・押下時の色を変更。新しいタブで開くことが分かる印を追加
- **「…」メニュー**：タグ・タイトル編集、URLコピー、確認付き削除を集約
- **保存済み表示**：現在開いているページを既に保存していれば「✓ 保存済み」とタグを表示。ブラウザでタブを切り替えたときも再判定
- **タグの一括管理**：タグ名の変更／既存タグへの統合／削除を行い、保存済みブックマークと保存ボタンの設定に反映。削除時は影響件数を示して確認、ブックマーク本体は残します。タグが唯一の割り当てとなっている保存ボタンがあれば、先に設定の変更が必要です
- **操作通知**：保存・タグの追加・重複などの結果を短時間表示
- **バックアップ**：ブックマークのお気に入り情報を追加

## v0.3.0 の変更点

- **「あとで見る」**：Webメールを含む現在のページを「メール」「Web」の文字ボタンで即座に保存。保存ボタンを追加・編集・削除でき、各ボタンに複数の自動付与タグを設定できます
- **保存済み一覧**：タイトル・URL・タグで検索、タグ別フィルタ、一覧からのタグ追加・解除、タイトル変更、個別削除。保存済みURLは新しいChromeタブで開きます
- **重複防止**：同じURLを別の保存ボタンで押した場合は新しい項目を作らず、既存の項目にタグを追加します
- **「TOPに戻る」**：設定配下の各画面と保存ボタン設定画面の下部に、利用画面へ直接戻るボタンを配置
- **バックアップ**：「あとで見る」のブックマーク、タグ、保存ボタン設定も一括バックアップに含めます
- **初期状態**：従来どおり「定型文」のみ表示。「あとで見る」は「＋ 機能」→「表示する機能」からONにします
- **権限**：現在のタブのURL・ページタイトルを取得するため `tabs` 権限を追加します。閲覧ページ全般へのアクセス権限（`host_permissions`）は追加しません

## あとで見る の操作

1. 「＋ 機能」から「あとで見る」を有効にします
2. Garoonなどで保存したいページを開きます
3. 「あとで見る」を表示し、「＋ メール」または「＋ Web」を押すと現在のページURL・タイトル・タグが端末に保存されます（同じURLはタグを追加）
4. 保存済みのタイトルをクリックすると**新しいタブ**で元ページを開きます
5. 一覧の「タグ編集」からタグの付け外し、タグの新規作成、タイトル変更、削除ができます
6. 「保存ボタンを編集」からボタン名と付与タグのプリセットを編集・追加・削除できます

**注意**：保存するのはURL・ページタイトル・タグ・日時です。メール本文や添付ファイルを読み込みません。ただし、メールの件名・URLに機密情報や一時的な認証情報が含まれる場合があるため、共用PCやバックアップの保管場所に注意してください。ログインセッションが切れた場合は、再ログインが必要です。

## v0.2.1 の変更点

- 提供されたキャラクターをChrome拡張のアイコン（16・32・48・128px）とサイドパネル左上のロゴに設定
- 配布用ZIPには画像4ファイルを追加。機能や保存データの形式はv0.2.0から変更なし

## 主な機能

- **定型文コピー**：検索、「すべて／★ お気に入り／個人／組織共通」の切り替え、個人文の登録・編集・削除、共通文の個人用コピー。お気に入りの★は黄色
- **日付ツール**：今日の日付を西暦／和暦でコピー、西暦年⇔和暦年の表示だけの相互変換、指定日からの暦日加減算と曜日表示
- **画像変換**：JPEG/PNG/HEICのドロップ取り込み、リサイズ・圧縮、画像／ZIPでの保存
- **機能表示のカスタマイズ**：初期表示は定型文のみ。上部「＋ 機能」から日付ツールを追加・非表示にできます。シンプル／拡張の2モードは廃止しました
- **組織共通データの管理**：配布JSONを確認して取り込み、セット単位で有効・無効、詳細画面で削除。無効なセットはすべての定型文タブから非表示となり、お気に入りやデータは維持されます
- **設定**：機能表示／組織共通データ／バックアップ・復元に分離。説明は「？」から確認可能
- **一括バックアップ**：個人定型文・お気に入り・機能表示設定・共通セットの有効状態・ブックマークをJSONで保存・復元。組織共通本文は別管理
- **開発者メニュー**：設定画面のバージョンを5回クリックすると表示。組織共通JSONの編集・書き出し、任意でこのPCへの反映に対応

## 更新について

v0.5.0はv0.4.0の機能を維持し画像変換を追加します。今回、既存データの移行検証は必須要件としていません。重要なデータがある場合は更新前に現在の「バックアップ・復元」でバックアップしてください。

## v0.1.x からの更新注意

**v0.1.xからv0.2.0への自動データ移行は行いません。** 新しい保存領域を使うため、旧版で保存した定型文・お気に入りはv0.2.0に自動で現れません。必要な情報は更新前に別途控えてください。v0.2.0以降のバックアップ形式を引き続き利用できます。v0.3.0からはブックマークもバックアップ対象です。v0.2.1の保存済み個人データ・設定はv0.3.0に引き継がれます。

拡張機能のIDを保つため、**以前と同じ展開フォルダへファイルを上書き**し、Chromeの `chrome://extensions` で「再読み込み」してください。別フォルダから新規読み込みすると別の拡張機能扱いになる場合があります。

## 配布と導入

配布用ZIPは [GitHub Releases](https://github.com/rmatsuoka-jpn/urachan-tool/releases) から `urachan-tool-v0.5.0.zip` を取得します。GitHubの「Source code (zip)」ではありません。

1. ZIPを解凍し、`manifest.json` のあるフォルダを用意します
2. Chromeで `chrome://extensions` を開き、デベロッパーモードをONにします
3. 新規導入時は「パッケージ化されていない拡張機能を読み込む」でフォルダを選びます。更新時は既存フォルダを上書きして「再読み込み」します
4. ツールバーの拡張機能ボタンからサイドパネルを開きます

配布ZIPは本体ソース6ファイル（`manifest.json`、`background.js`、`panel.html`、`panel.css`、`panel.js`、`image-tools.js`）、アイコン4ファイル、`LICENSE`、`THIRD_PARTY_NOTICES.md`、`vendor/heic/`の3ファイル、`vendor/jszip/`の2ファイル（計17ファイル）を収録します。`vendor/`以下のフォルダー構造を変えずに解凍してください。設計書やJSONデータは含みません。

Chrome 116以降を対象としています。職場PCの拡張機能インストール・データ持出しに関する規則を守ってください。閉域環境では外部のサービスにアクセスしません。

## 組織共通JSON

配布形式は `format: "urachan-shared"`、`version: 1` のJSONです。架空データの例は [examples/common-sample.json](examples/common-sample.json) を参照してください。

設定 → 組織共通データでJSONを取り込みます。同じセットIDなら既存セットを更新し、**そのセットの有効・無効状態は維持**します。削除時は該当セットの共通お気に入りを解除し、個人用に複製した定型文は残します。

配布JSONの作成・編集は開発者メニューで行い、「JSON書き出し時にこのPCにも反映する」の初期値はOFFです。「このPCに反映」の単独ボタンは引き続き利用できます。

組織共通データの編集は通常画面ではできません。セット内容の編集と配布は開発者メニューから行います。

## プライバシーと保存場所

個人用データは `chrome.storage.local` に保存されます。共有PCの同じChromeプロファイルでは別の利用者にも閲覧される可能性があります。実際の機密・個人情報をテストデータとして保存しないでください。

このリポジトリは**Public**です。住民・職員の個人情報、実在の庁内文書、内部システムURL、認証情報などはコミットしないでください。公開リポジトリはソースコードと架空のテストデータの管理専用です。
